# Terminal UI DOX

## Purpose

- Own the interactive Bubble Tea interface, chat transcript, composer, forms, wizards, selectors, activity, visual capture fixtures, and local input workflows.

## Local Contracts

- Keep rendering responsive and deterministic: bounded live history, owned async Markdown rendering, coalesced streaming, exact semantic backgrounds/padding/scrollbars, and no blocking filesystem or theme work in the event loop.
- Keep alternate-screen rendering single-owned and bounded across sleep/display restoration: filter invalid and duplicate dimensions before Bubble Tea's renderer, re-establish alternate-screen ownership and repaint on terminal focus or explicit Ctrl+L, and never drive full-frame cache invalidation from an unconditional timer.
- Drive the header logo from explicit foreground activity and the runtime's authoritative global `LiveJobs` projection: foreground uses the existing 100 ms frame interval, any live job without local foreground activity uses 200 ms, including other conversations and jobs without task/goal leases, and idle immediately renders `○○` and schedules no ticks regardless of prior frames or transcript state. Fence timer generations across transitions so stale ticks cannot duplicate or revive animation.
- Render the header's right side as Telegram, WhatsApp, authoritative nonterminal goals, authoritative nonterminal tasks, live jobs, retained logs, and finally the meaningful embedded build version with a `v` prefix. For a launcher-validated npm TUI, refresh update availability asynchronously no more than hourly and place one semantic-warning-colored `⚠` beside the version only when a strictly newer version is known. Omit unavailable/development placeholders and drop the complete version/warning item before higher-priority status on narrow terminals. Poll durable counts through shared owner state, keep bounded census diagnostics out of the header, and choose singular labels only for an exact uncompressed count of one.
- Forms preserve dirty state through save/discard/keep-editing confirmation; selectors and wizards retain their documented navigation, screen stack, validation, and transactional persistence behavior.
- Model selection uses compact dependent effort and service screens only when supported and commits the complete selection only at the final step.
- Required pre-workspace screens use the canonical theme and selection controls. The ancestor-workspace chooser defaults to its parent action, exposes exactly parent/local/exit actions, and maps Escape and Ctrl+C to non-mutating exit.
- A `/new` welcome screen may carry a new durable conversation identity; apply it atomically with clearing only the live transcript while leaving the prior history resumable.
- Register the displayed conversation with the owner before entering the TUI, renew its bounded live lease while open, update the renewal identity on conversation switches, and release it on clean exit.
- Serialize pasted-file preparation, preserve dispatch ordering and full text, bound queues and diagnostics, and inspect generated PNGs after meaningful visual or theme changes.
- Use the textarea's logical range replacement for atomic attachment deletion as well as preparation completion; a whole-buffer reset followed by caller-owned cursor walking loses the visible editing position.
- `terminal_input` frames complete CSI/SGR/X10/focus/key sequences across arbitrary OS reads before Bubble Tea interprets them. Paste payloads stay literal, malformed/unsupported control reports are consumed at that boundary, and a bounded polling read permits cancellation before terminal release/restore. All interactive entry points use it; no headless caller does. Bubble Tea owns raw mode, mouse/paste/focus capture, alternate screen, and shutdown cleanup: its shared renderer clears the application-owned alternate display after rendering stops and before restoring the ordinary screen, preserving shell history and diagnostics. Ctrl+C selection/clear/stop priority is unchanged; return from terminal copy reenables mouse capture.
- Preserve the pinned Bubble Tea keyboard frame shapes, including rxvt dollar endings, console function keys, DECCKM variants and Escape-prefixed Alt keys. Retain an Alt prefix only for known supported keyboard shapes; unknown controls must reach Tea as a complete unprefixed report or be discarded. Alt+Escape and the focus-out/DECCKM prefix use the same bounded Escape timeout. The identical focus-out-plus-letter and DECCKM bytes cannot be distinguished; document the key-first choice within that interval.
- The locked terminal output retains the underlying file descriptor and read/close capabilities required by Bubble Tea to discover initial dimensions and watch OS resize events. Real PTY verification starts with unset model dimensions and exercises SIGWINCH, composer reflow, and pane geometry; synthetic WindowSize messages alone do not verify that boundary.
- The root module selects the narrowly patched `third_party/bubbletea` dependency: output-terminal discovery is immutable before resize handling starts, including F6 restore. Keep this race fix at the library owner and retain the real SIGWINCH regression.
- `editing` maps pane hits to source-indexed Markdown/textarea layout. Starting a transcript drag in content latches content-only copy across messages; starting in the label/gutter latches whole-message copy with labels and real-line prefix spacing. Display padding, inline-code padding, spinner cells, ANSI, and scrollbars have no copyable ranges. Selections survive reflow; selected streamed text retains its existing interpretation while appended source appears, deferring changed Markdown formatting until selection clears. Eviction/conversation changes clear invalidated selections.
- Double-click content selects its whitespace-delimited grapheme word (punctuation included); triple-click selects its logical line across soft wraps without a newline or label. Whitespace selects its same-line run. Count released primary clicks within 500 ms on the same row, within one column and in the same pane; fourth clicks restart. Actual-character hits exclude synthetic padding, gaps and row-end fill. Held dragging retains the initial word/line bounds and extends or shrinks by whole units in either direction, including autoscroll and moved release. Release preserves the range; drag, wheel, keys, resize, focus/screen changes and terminal copy reset click counting. Reuse textarea word/line range helpers for both panes.
- Mouse wheels scroll the pane under the pointer without moving the composer caret. Dragging beyond either pane extends selection with a bounded 50 ms timer, up to three rows per tick; release, reentry, boundary, Escape, observed focus loss, screen change, resize, and terminal copy fence the timer. History is read-only. New selection/focus clears the other pane; typing returns output focus to input. Shift-click extends an existing anchor.
- Composer Shift+arrows/Home/End and Ctrl+Shift navigation extend selection; Ctrl+A selects all, Home/Ctrl+E retain line navigation, Ctrl+Left/Right and Alt+B/F move words, Ctrl+Delete (when encoded)/Alt+D and encoded Ctrl+Backspace/Alt+Backspace/Ctrl+W delete words. PageUp/PageDown and Alt+Up/Down scroll output. Preserve send, Shift+Enter newline, stop, quit, and modal behavior; copy takes precedence only for a focused selection.
- Ctrl+Z/Ctrl+Y silently undo/redo only the focused composer via textarea-owned draft history; output and modal scopes never edit the composer or suspend the process. Delegate key grouping boundaries to the widget so surrounding dispatch preserves compatible deletion runs. Reset history and cancel queued/in-flight paste work on submission, clear, command-picker draft replacement and conversation changes. Fence native clipboard and prepared attachment completion with the widget history generation so late results cannot overwrite an undone/redone/replaced draft. Attachment conversion is a separate undoable range replacement; retain token metadata while its label exists in the current draft or undo/redo history, prune unreachable metadata, and never repeat preparation or remove files during undo/redo. Give prepared attachments distinct labels across all retained metadata (suffix basename collisions), and expand only original draft tokens in one nonrecursive pass so historical copies cannot corrupt the current attachment's Markdown.
- Keep pasted text editable, including long and multiline text; only prepared file attachments use atomic display tokens. Insert validated literal text before asynchronous preparation; ordinary completion never resets the composer. Apply an attachment only to a unique unchanged occurrence of its pasted text through the textarea range-replacement contract, preserving current caret/selection. Changed or repeated source and oversized conversion retain the current text with visible feedback. Normalize CRLF once, retain real newlines/tabs/indentation, and reject an oversized edit without deleting its selection. Native clipboard operations run asynchronously; copy always offers base64 OSC 52 through the same locked writer as rendering, even if a local helper succeeds, and retains an internal copy. Ctrl+V can paste that fallback; terminal-owned Ctrl+Shift+V/Cmd+V and Shift+drag remain available. Never claim host clipboard delivery is acknowledged, and show no routine copy-success/request notice. Actionable failures replace footer hints until the next input.
- F6 uses Tea Exec to leave the alternate screen, home then erase below (ED 0) to reuse visible ordinary rows in place, and print only the sanitized semantic selection once. Avoid ED 2, which can archive the old display in normal-screen terminals, and never erase scrollback (ED 3). Previous copy rows already scrolled into history cannot be selectively overwritten; long selections deliberately retain native scrollback. Tea stops its renderer and releases mouse/focus capture; Exec restores/repaints it before the result callback, which must not toggle screens again while rendering runs. The bounded raw reader reenables bracketed paste solely to discard paste atomically; native mouse selection, copy shortcuts and scrollback stay available. Escape, Enter, Space, Backspace, Delete, Tab or any supported F key returns through the pinned Tea key decoder; drain complete coalesced input through an observed quiet interval before restoring modes so key/paste tails cannot reach the composer. Sanitize source controls, preserve logical newlines and tabs, and retain draft/selection/focus/live state. Restore dimensions and mouse capture on return or error. Ctrl+Z never calls Tea Suspend: a TUI may host the shared primary.
- Run root framing, semantic range/highlight, and real synthetic PTY checks, including terminal copy and mode restoration. PTY fixtures must close their parent slave descriptor before waiting for output EOF. Keep fixtures isolated from application owners, actual desktop clipboard, private histories, and remote channels; inspect PNG captures and document remaining local-emulator/SSH checks in `docs/tui-editing.md`.
- Generate one private stable source-message identity before each local submission and retain it across loopback dispatch so retries cannot duplicate work.
- Follow explicitly marked local stalled-message recovery terminals from the private conversation history so a recovery that finishes outside an inbound TUI request stream appears exactly once in the live transcript; reconcile its observed activity placeholder without disturbing a newer response stream, do not acknowledge it as a task notification, follow it at the conversation tail, and preserve intentional upward scroll with a visible new-message status.
- Consume the caller-scoped canonical recovery activity count from owner shared state for the selected conversation only, preserving overlap references without exposing conversation identities in shared projections. When a durable terminal arrives ahead of its polled inactive edge, settle its visible reference once and credit that exact later edge so it cannot consume another overlapping recovery.

- Completing a dependent model selector refreshes the preserved configuration action row from the application-owned `SavedControl`, retaining unrelated unsaved fields; cancellation restores the parent unchanged.
